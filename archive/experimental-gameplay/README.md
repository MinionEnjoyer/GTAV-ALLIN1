# Retired built-in Experimental Gameplay

These files preserve the former built-in `allin1.experimental-gameplay`
descriptor and its NPC-physics experiment notes. They are archival evidence,
not a package source or active user guidance.

The launcher no longer discovers, registers, ships, or configures this built-in
package. Do not copy these files into a game installation or treat the prior
NPC-physics/police behavior as supported.

Independently installed user-authored experimental weapon and pedestrian
packages remain separate receipt-owned content. Their availability and settings
are determined by each installed package's current manifest and runtime checks,
not by this archive.

Retired native implementation and test material, when retained, belongs under
the `native/` subtree so it remains distinct from the archived descriptor and
documentation.
