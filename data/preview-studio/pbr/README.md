# Vehicle studio texture assets

2K diffuse, OpenGL normal and roughness maps, downloaded unmodified from Poly
Haven on 2026-09-06. Downloads were checked against the published API MD5 values.
These texture assets are CC0; this does not change the license of ALLIN1 code.

- Asphalt 01 — Charlotte Baglioni / Dario Barresi: https://polyhaven.com/a/asphalt_01
- Concrete — Rob Tuytel: https://polyhaven.com/a/concrete
- Wood Planks — Amal Kumar: https://polyhaven.com/a/wood_planks
- Asset license: https://polyhaven.com/license
- CC0: https://creativecommons.org/publicdomain/zero/1.0/

Art-directed material scale: asphalt 6 meters per repeat (enlarged aggregate to
remain visible in small cards); concrete 4 meters per repeat. Asphalt is
desaturated/darkened in the shader; original downloaded files are unmodified.
Diffuse is sRGB; normal and roughness are non-color data. These are bundled
assets, not downloads performed by the launcher. Weapons/gear remain pegboard
except throwables, which use the wood/concrete warehouse crate scene.
