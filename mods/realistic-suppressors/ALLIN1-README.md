# Suppressors Enhanced 1.1.0 — ALLIN1 package

This is the recommended Suppressors Enhanced distribution for GTA V Enhanced
Story Mode. ALLIN1 manages installation, configuration, updates, disable and
re-enable operations, and clean removal.

## Install

1. Extract this archive to a folder.
2. Open **Packages** in the ALLIN1 launcher.
3. Choose **Import & install package** and select this folder's `mod.toml`.
4. Open **Content → Suppressors Enhanced**, adjust the settings, and apply.
5. Restart Story Mode or reload ScriptHookVDotNet scripts.

Do not install the separate standalone OIV at the same time. The two variants
use the same script and heat-DLC paths.

## Included gameplay

- Witness-aware stealth for supported vanilla suppressors, including those
  purchased through Ammu-Nation.
- Weapon-specific heat with gradual center-out incandescence.
- Temperature-scaled barrel smoke with a stronger critical-heat plume.
- Optional persistent wear and breakage with a cosmetic spark and metallic pop.
- Optional live can-temperature diagnostic readout.

The archive does not include GTA V files, ScriptHookV, ScriptHookVDotNet,
OpenRPF, or any other third-party runtime.
