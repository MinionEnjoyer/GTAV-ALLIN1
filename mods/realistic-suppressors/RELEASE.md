# Suppressors Enhanced 1.1.0

Realistic suppressor stealth, gradual center-out heat glow, critical smoke,
weapon-specific wear, and spark-pop breakage for GTA V Enhanced Story Mode.

## Choose one installation method

### Recommended: ALLIN1 launcher

1. Extract `Suppressors-Enhanced-ALLIN1-1.1.0.zip`.
2. In ALLIN1, open **Packages** and choose **Import & install package**.
3. Select the extracted folder's `mod.toml`, apply the settings, and restart
   Story Mode.

### Without ALLIN1

1. Install ScriptHookV, ScriptHookVDotNet 3, and OpenRPF.
2. Open `Suppressors-Enhanced-Standalone-1.1.0.oiv` in an Enhanced-compatible
   OIV installer such as CodeWalker OIV Package Installer.
3. Select the GTA V Enhanced folder and install.

Do not install both variants at the same time. Neither archive includes GTA V
files or third-party runtime dependencies.
