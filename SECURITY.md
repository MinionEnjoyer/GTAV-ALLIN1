# Security policy

## Supported version

Security fixes target the latest published ALLIN1 release and the current
`main` branch. Older portable builds should be upgraded before troubleshooting.

## Reporting a vulnerability

Do not disclose an exploitable vulnerability, credential, private game path or
sensitive log in a public issue. Use the repository's **Report a
vulnerability** option under GitHub Security when available. If that option is
not shown, contact the repository owner through the GitHub profile before
sharing sensitive reproduction material.

Include the ALLIN1 version, GTA edition, affected workflow, impact and the
smallest safe reproduction you can provide. Never upload proprietary GTA files,
third-party mod payloads, tokens or personal configuration.

Ordinary crashes, compatibility problems and non-sensitive bugs belong in the
public bug-report template.

## Release trust

ALLIN1 portable releases are currently unsigned. Download only from this
repository's official Releases page and verify the published SHA-256 file.
Checksums detect changed bytes; they do not authenticate an unknown publisher.
Do not disable Windows security protections to install ALLIN1.
